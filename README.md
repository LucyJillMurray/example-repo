# Level 1 – Python for Software Engineering

A collection of practical tasks completed as part of the HyperionDev Level 1 Software Engineering bootcamp. Each task focuses on a specific Python concept, building from basic syntax through to object-oriented programming and a final task-management capstone.
Summaries done using Claude.

## Task Summaries

### Module 1 – Python Fundamentals

- **M01T01 – Pseudocode**: Wrote pseudocode to plan out programming logic before implementation.
- **M01T02 – Your First Computer Program**: Created a basic "Hello World" program and a simple unit conversion script as an introduction to writing and running Python code.
- **M01T03 – Variables**: Practised storing and printing user details using variables of different data types.
- **M01T04 – Strings and Numerical Data Types**: Performed string manipulation, replacements, and integer arithmetic across several short challenge programs.
- **M01T05 – Control Structures**: Built an age-quiz program using `if`, `elif`, and `else` statements together with the Boolean data type.
- **M01T06 – Logical Operators**: Wrote an awards-decision program that uses logical operators to evaluate multiple conditions.
- **M01T07 – Capstone (Variables and Control Structures)**: A finance calculator that lets the user choose between an investment calculation (simple or compound interest) and a home-loan repayment calculation.

### Module 2 – Data Structures and Functions

- **M02T01 – Lists**: Explored list creation, indexing, and the different data types a list can hold.
- **M02T02 – Iteration**: Used `for` and `while` loops to print number patterns and repeat actions.
- **M02T03 – Defensive Programming (Error Handling)**: Identified and fixed errors in broken example scripts to practise reading and resolving Python errors.
- **M02T04 – String Handling**: Wrote a program that alternates the case of every character in a string.
- **M02T05 – I/O Operations**: Read from and wrote to text files, including a date-of-birth reader and a student registration form.
- **M02T06 – Lists and Dictionaries**: Calculated the total cost of items in a cafe menu using a dictionary, and looped through lists of student data.
- **M02T07 – Built-in Functions**: Practised using built-in functions for float manipulation and worked with a jokes program.
- **M02T08 – User-defined Functions**: Built a holiday cost calculator using custom functions for flights, hotel, and car-hire costs.
- **M02T09 – Debugging (Stack Trace)**: Used the stack trace to locate and fix bugs in provided programs.

### Module 3 – OOP, Algorithms, and Capstone

- **M03T01 – Exception Handling**: A calculator app that reads/writes results to a file and uses `try/except` blocks to handle invalid input and missing files.
- **M03T02 – OOP Classes**: Created `Student` and `Email` classes to practise defining classes, attributes, and methods.
- **M03T03 – OOP Inheritance**: Wrote classes that inherit from a parent class and override methods to demonstrate inheritance and polymorphism.
- **M03T04 – 2D Lists**: A Minesweeper-style program that uses a 2D grid to count mines adjacent to each cell.
- **M03T05 – Recursion**: Two recursive functions — one that sums the digits of a number, and one that finds the largest number in a list.
- **M03T06 – Sorting and Searching**: Implementations of merge sort and a small album-management program that sorts and searches records.
- **M03T07 – OOP Synthesis**: An inventory program for a shoe warehouse, using a `Shoe` class and reading/writing data to a text file.
- **M03T08 – Shell Scripting**: PowerShell scripts that practise navigating directories, creating folders, and using `if` statements in the shell.
- **M03T09 – Version Control and Git Basics**: This task — initialising a Git repository, committing changes, and pushing to GitHub.
